# RetailPilot

Responsive operational dashboard for retail networks, based on the supplied 10-screen product flow.

## Included in the first prototype

- Dashboard
- Stores list with search/filter/sort
- Store detail
- 4-step visit flow
- Tasks and new task creation
- Staff schedule
- Reports
- Responsive desktop/mobile navigation
- Demo data and local interactive state

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Current scope

This is a functional frontend prototype. Data is currently demo data stored in the client. Authentication, database persistence, push notifications, photo storage, role permissions and ERP/POS integrations should be connected in the next phase.
